# Simple AI Inference Analyzer

A simple Python application for analysing AI inference data from a CSV file.

## Features

- Load inference data from CSV
- Filter records using confidence threshold
- Calculate basic statistics
- Count detected object classes
- Save filtered data to CSV
- Generate a bar chart of detected objects
